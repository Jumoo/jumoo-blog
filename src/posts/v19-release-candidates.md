We've released v19.0.0-rc1 of our packages, ready for the Umbraco v19 release candidate.

These are release candidates, so you'll need to include prereleases to see them in your package manager.

## What's out

- [uSync](https://github.com/KevinJump/uSync/releases/tag/v19.0.0-rc1)
- [uSync.Complete](https://www.nuget.org/packages/uSync.Complete/19.0.0-rc1)
- [uSync.Forms](https://github.com/Jumoo/uSync.Forms/releases/tag/v19.0.0-rc1)
- [uSync.Umbraco.Commerce](https://github.com/Jumoo/uSync.Umbraco.Commerce/releases/tag/v19.0.0-rc1)
- [Translation Manager](https://www.nuget.org/packages/Jumoo.TranslationManager/19.0.0-rc1)
- [Maintenance Mode](https://github.com/Jumoo/Our.Umbraco.MaintenanceMode/releases/tag/v19.0.0-rc1)

<pre class="nuget">
dotnet add package uSync.Complete --version 19.0.0-rc1
</pre>

The rest of our packages will follow before the full v19 release.

If you're trying out the Umbraco v19 RC, give these a go and let us know on GitHub if anything breaks.
