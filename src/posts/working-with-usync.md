uSync can be used in a number of ways; it can help with source control, development teams, or site deployment and for each of these ways you can have uSync do all sorts of different things to meet your needs.

Over time I have put together a couple of guides to help get people started. These are not the definitive way to use uSync, you can use it how ever you like, but if you are struggling with some of the details to get you started these might help you.

*   [Multiple Developers, Multiple Databases, One Site](http://blog.jumoo.co.uk/2017/umbraco-multiple-developers-multiple-databases-one-site/)
*   [Local Deployment with uSync](http://blog.jumoo.co.uk/2017/local-deployment-with-usync/)
*   [Deploying Umbraco to Azure with Visual Studio Online](http://blog.jumoo.co.uk/2017/deploying-umbraco-to-azure-with-visual-studio-online/)
*   [Deploying Umbraco with Team City and Octopus](http://blog.jumoo.co.uk/2017/deploying-umbraco-with-team-city-octopus-deploy/)
Again these are not complete (there are many other things you can do with Azure and Octopus) but the build the core of how uSync can work in each of these environments, hopefully they are helpful.
